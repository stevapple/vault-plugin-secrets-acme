# Code of conduct

This project adopts the [Contributor Covenant][cc], version 3.0, as its code of
conduct. The full text is published at
<https://www.contributor-covenant.org/version/3/0/code_of_conduct/> and is not
copied here, so that it cannot drift out of date against the version this
project has actually adopted.

In short: participate in a way that a reasonable person would call
professional, assume good faith, and accept that maintainers may decline a
change without that being a judgement of the person proposing it.

## Reporting

Report conduct concerns privately to the maintainers by opening a
[private security advisory][report] — it is the only private channel this
repository has, and it reaches the maintainers and no one else. Say plainly
that the report is about conduct rather than a vulnerability.

Reports are handled confidentially. Someone reported on will not be told who
raised it.

A vulnerability is not a conduct matter — see [SECURITY.md](SECURITY.md).

[cc]: https://www.contributor-covenant.org/
[report]: https://github.com/stevapple/vault-plugin-secrets-acme/security/advisories/new
